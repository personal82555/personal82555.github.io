## 下午 3 点 17 分，第 8 版方案又被打回了

你懂那种感觉：脑子是木的，刷手机越刷越烦，站起来走一圈又坐回工位。

我后来养成一个习惯——**开一盘象棋，只走 3 步** 。

马八进七，兵七进一，炮二平五。就这三步，大概 40 秒。注意力被从表格里拽出来，又被还回去。回过神接着改方案，思路居然通了。

关键是这盘棋不用开 App、不用登录、不用等匹配。我打开的是**自己 NAS 上的内网地址** ：

**`http://你NAS的IP:7025`**

## 主角：8 项 AI 功能（这才是我装它的原因）

![更多功能面板](https://img.88531.cn/i/2026/10/08/6ac7649b8b75f.png)

点对局页的 **「✨ 更多功能」** ，8 项功能全在这里。

### 1️⃣ AI 教练：每一步告诉你该怎么走，而且说人话

![AI 教练中文建议](https://img.88531.cn/i/2026/10/08/6ac7648d86398.png)

注意看它的说法：**「左起第 2 列的炮往前走 7 格，吃掉对方的车」** ——不是 `炮二平五` 这种棋谱术语，也不是 `b8 → h8` 这种字母坐标。**完全没下过棋的人也能看懂它在说什么。**

还有 5 种教练人格可以换：务实教练、严厉教练、温柔启蒙、**毒舌损友** 、老棋手（会甩棋谚的那种）。嫌打字慢还能开 🔊 语音朗读，它直接念给你听。

### 2️⃣ 走法点评：这步亏了多少分，当场算给你看

![走法点评 这步亏了](https://img.88531.cn/i/2026/10/08/6ac7649173c3d.png)

你落子的瞬间，本机的 α-β 搜索引擎会把「你这步之后的局面」和「引擎的最优解」对比：

> ⚠️ **这步亏了约 610 分（≈ 一个马或炮）。更好的下法：炮在左起第 2 列、从红方底线往上第 3 行，往前走 7 格，吃掉对方的马。**

  * 亏在哪儿、亏多少、怎么补救，一句话说完
  * **本机计算，零延迟、不联网、不烧 token**
  * 下得好它也会夸：「👍 好棋！比引擎的首选还强 1830 分」

### 3️⃣ 赛后 AI 复盘

一盘结束，弹窗里点「🧠 AI 复盘这盘棋」，它会用 **3 句话** 讲清楚：① 胜负关键在哪 ② 双方最大的失误 ③ 一条最实用的改进建议。配上不同人格，毒舌模式的复盘尤其解压。

### 4️⃣ 每日一题 + AI 出新残局（出的题必须先过程序校验）

![每日一题](https://img.88531.cn/i/2026/10/08/6ac7649ee1a7d.png)

  * 每天一道新残局，按用时评 **S / A / B / C** 级，还有 🔥 连续打卡天数——摸鱼顺便变成打卡
  * 填了模型可以让 AI **现场出题** ，但出的局面会**先在本机校验** ：象棋必须真的「一步将死」、五子棋必须真的「一步成五」，**验不过就自动回退本地题库** ，绝不给你一道解不开的题

### 5️⃣ 棋风画像与弱点报告

它会读你的真实战绩，直接给结论：

  * 胜率、连胜、每局用时
  * **「输的局明显下得更快（44 秒 vs 135 秒）→ 你输在太急，多想 5 秒再落子」** ——这是它从我自己的数据里算出来的，不是套话
  * 有模型的话，还能让 AI 把它写成一份完整的弱点报告

### 6️⃣ 对手嘴炮（对局更有味道）

AI 吃掉你的子、将军、赢你的时候，会甩一句骚话（本地金句库；填了模型就让它现场发挥）。比如吃你子的时候来一句：**「哎哟，送子观音？」**

### 7️⃣ 战绩海报：文字可以自己改，一键保存发朋友圈

![战绩海报](https://img.88531.cn/i/2026/10/08/6ac764a213e05.png)

海报里的标题、金句、底部宣传语**全部可以自己编辑，边打字边预览** ，点「存为我的默认」下次接着用；超长文字会自动缩字，不会溢出。数据列（手数 / 用时 / 难度）取自本局真实战绩，没法作假。

### 8️⃣ 开局库讲解 + 军棋记牌推理

  * 象棋 6 种开局（中炮、仙人指路、起马、飞相……）全是中文讲解 + 常见陷阱
  * 军棋的「🔍 记牌推理」实时告诉你：**50 枚棋子还剩哪些没露面、还剩几个司令和炸弹** ，并提醒你「想探牌就用工兵去撞」

![军棋记牌推理](https://img.88531.cn/i/2026/10/08/6ac764a5120eb.png)

### 💡 最关键的一点：不填模型，这些也全部能用

我上面所有截图，除「AI 现场生成」那几项外，**都是在没有配置任何大模型的情况下跑的** ：

状态 | 能用什么  
---|---  
**没填模型** | 走法点评、每日一题（本地题库）、棋风统计、自适应难度、战绩海报、记牌推理、嘴炮（本地金句）、开局库 —— 全部可用  
**填了模型** | 以上再 + AI 现场出题、AI 弱点报告、AI 金句、AI 嘴炮、AI 开局讲解，且生成内容都会先本地校验  
  
填模型也简单：**任意 OpenAI 兼容接口** 都行（BaseUrl / KEY / 模型名三个框），KEY 输入框默认打码、点 👁 才显示，填完点旁边的 **「🔌 测试」** 立刻告诉你通不通、不通是哪里的问题（KEY 失效 / 模型名错 / 地址不可达）：

![模型设置与测试按钮](https://img.88531.cn/i/2026/10/08/6ac764a8eea07.png)

（没有 KEY 的话，我自己在用的网关有免费额度：`ai.88531.cn`，页面里点「免费 获取KEY」就能领。）

另外面板里写得很明白：**KEY 只保存在你自己的浏览器（localStorage），不上传、不写入服务器** ——服务器上没有任何存放 KEY 的文件，镜像里也没有；只有你发起 AI 请求时，浏览器才把 KEY 临时发给模型接口。

## 为什么它比刷手机更适合「工作间隙」

| 刷短视频 / 刷微博 | 来一盘棋（20 分钟倒计时）  
---|---|---  
结束方式 | 无限下拉，停不下来 | **到点自动判负** ，规则替你喊停  
用完的感受 | 越刷越空 | 主动做了个决策，脑子被激活  
数据去向 | 平台拿走 | **全在你自己 NAS 里**  
花多少钱 | 时间 + 推荐算法 | 0  
  
配套的「防沉迷」细节也做全了：

  * ⏱ **倒计时** 1 / 3 / 5 / 10 / 20 / 30 / 60 分钟任选，超时判负（像棋钟）
  * 💾 **每 5 分钟自动存档** ，切后台、关页面还会**立即** 再存一次
  * 🚪 **离开提醒** ：对局没结束时点到别的页面、刷新、关标签，都会先问你一句
  * ↩ 悔棋、🔄 重新开始、🎯 残局、🏆 排行、💾 存档，全在头排一行

## 飞牛部署：4 行命令的事

SSH 进飞牛，或者在 Docker 面板里执行：

**📦 新进展** ：已打包**飞牛应用商店安装包** （`.fpk`，真机安装/启停/卸载全流程验证通过），即将上架应用中心——到时在应用中心搜索「摸鱼棋乐」一键安装，无需命令。

最快方式：**不用克隆源码，直接拉公开镜像** （GitHub Actions 自动构建更新）：
[code] 
    docker pull ghcr.io/personal82555/moyu-qile:latest
    
    docker run -d --name moyu-qile --restart unless-stopped \
      -p 7025:7025 -v "$PWD/data:/app/data" \
      ghcr.io/personal82555/moyu-qile:latest
    
[/code]

也可以从源码构建：
[code] 
    git clone https://github.com/personal82555/moyu-qile.git
    cd moyu-qile
    docker build -t moyu-qile:latest .
    docker run -d --name moyu-qile --restart unless-stopped \
      -p 7025:7025 -v "$PWD/data:/app/data" moyu-qile:latest
    
[/code]

然后浏览器打开 **`http://飞牛的IP:7025`** ，手机同网段同样地址即可。

三个注意点：

  1. **`-v .../data:/app/data` 这个数据卷必须挂**——存档、战绩、路径配置都在里面，不挂重建容器就丢
  2. 端口冲突就改 `-p 7026:7025`
  3. 不想用 Docker 的话，`npm install && node server.js` 也能跑（需要 Node 20+）

镜像很小、内存占用不到 10 MB，跟飞牛上其它服务完全不打架。
