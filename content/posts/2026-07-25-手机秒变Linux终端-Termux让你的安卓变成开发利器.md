##  什么是 Termux？ 

    简单说：**安卓手机上的Linux终端+包管理器+开发环境，三合一** 。不需要root，不需要刷机，装上就能用。 

    Termux是一个开源的安卓终端模拟器，它在你的手机上提供了一个完整的Linux环境。你可以用它安装Python、Node.js、Git、Vim等开发工具，甚至跑一个Web服务器。更重要的是——它完全免费，没有广告，没有订阅。 

![](https://img.88531.cn/i/2026/07/25/6a64a6b147b67.png)

##  5大核心功能 

**1\. 完整的Linux终端**

    打开Termux就是一个黑底白字的命令行界面，支持Bash/Zsh。你可以像在电脑上一样敲命令：ls、cd、grep、ssh，全都能用。出差在外临时需要连服务器？掏出手机就行，不用背笔记本。 

**2\. 强大的包管理器**

    Termux自带pkg/apt包管理器，一行命令就能安装各种工具。想装Python？`pkg install python`。想装Node.js？`pkg install nodejs`。社区维护了上千个包，基本上你需要的命令行工具都能找到。 

**3\. SSH客户端内置**

    安装openssh包后，你的手机就变成了一台便携SSH客户端。服务器运维、远程调试，随时随地搞定。再也不用到处找电脑登远程桌面了。 

**4\. 编程环境随身带**

    Python、Ruby、Go、Rust、C/C++……这些编程语言都能在Termux里安装和运行。通勤路上写个小脚本、调试个代码片段，碎片时间也能利用起来。配合Vim或Nano编辑器，手机就是你的移动IDE。 

**5\. 文件系统互通**

    执行`termux-setup-storage`后，Termux可以访问手机的存储空间。你下载的文件、拍的照片，都能在终端里操作。反过来，用终端下载的文件也能直接在文件管理器里看到。

##  新手入门3步走 

    **第一步：安装Termux**  
    从F-Droid或GitHub下载APK安装包（不要从Google Play下载，那里的版本很旧）。安装后打开，你会看到一个黑色的命令行界面——恭喜，你的手机已经变身为Linux终端了。 

    **第二步：初始化环境**  
    第一次打开会自动初始化，稍等几秒。然后输入`pkg update && pkg upgrade`更新所有包。这一步很重要，确保你的环境是最新的。 

    **第三步：安装你需要的工具**  
    想用Python？输入`pkg install python`。想SSH连服务器？输入`pkg install openssh`。想编辑文件？`pkg install vim`。就这么简单。
