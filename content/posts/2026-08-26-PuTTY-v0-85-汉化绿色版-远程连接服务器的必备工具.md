# PuTTY v0.85 汉化绿色版 - 远程连接服务器的必备工具

你是不是经常需要远程连接服务器？用 Windows 自带的命令行？那可太痛苦了。PuTTY 这款经典的 SSH 客户端，程序员和运维人员几乎人手一个，小巧但功能强大。

## PuTTY 是什么？

PuTTY 是一款免费开源的 SSH 和 Telnet 客户端。简单说，它就是让你在 Windows 电脑上安全连接到远程 Linux 服务器的工具。别看它只有几 MB，该有的功能一样不少。

## 为什么选 PuTTY？

市面上 SSH 工具那么多，为什么 PuTTY 能火这么多年？因为它够简单、够稳定、够轻量。打开就能用，不用配置一堆东西。对于只需要基本 SSH 连接的用户来说，PuTTY 就是最省心的选择。

## 核心功能

![](https://img.88531.cn/i/2026/08/26/6a8e3c8434ff8.png)

**SSH 安全连接** ：支持 SSH-1 和 SSH-2 协议，加密传输所有数据。登录服务器、执行命令、传输文件，全程安全。

**密钥认证** ：除了密码登录，还支持 SSH 密钥认证。生成一对密钥，把公钥放到服务器上，以后登录再也不用输密码，既安全又方便。

**端口转发** ：支持本地端口转发和远程端口转发。比如你本地的 8080 端口想映射到服务器的 80 端口，PuTTY 几步就能搞定。

**会话管理** ：保存常用的连接配置（IP、端口、用户名），下次直接双击就能连。不用每次都手动输入，管理多台服务器也不怕搞混。

## 汉化版说明

原版 PuTTY 是英文界面，这个汉化绿色版已经翻译成中文，而且是绿色版不需要安装。下载解压就能用，U盘里放一个，走到哪都能连服务器。
