##  什么是 LocalSend？ 

简单说：**跨平台+局域网+免费开源，三合一的文件传输神器** 。

    LocalSend 是一款开源免费的文件传输工具，支持 Windows、macOS、Linux、Android、iOS 五大平台。它不需要联网，不需要注册账号，不需要第三方服务器——只要你的设备连着同一个 WiFi，就能像 AirDrop 一样即开即用。

    GitHub 70K+ 星标，全球下载量超过 500 万次，而且完全无广告、无追踪、无隐藏付费。说实话，现在还能找到这种良心软件真不容易。

##  4大核心功能 

**1\. 跨平台无缝传输**

    这是 LocalSend 最大的卖点。安卓传给 iPhone、Windows 传给 Mac、甚至 Linux 电脑之间互传，全部支持。以前苹果用户只能用 AirDrop，安卓用户只能用快牙，现在一个工具全搞定。你再也不用纠结「这个文件怎么传到那台电脑上」了。

**2\. 完全离线，无需互联网**

    LocalSend 只用局域网传输，数据永远不离开你的本地网络。这意味着什么？第一，速度快——以 WiFi 的最高速度传输，没有带宽限制；第二，安全——所有传输都用 HTTPS 加密，别人看不到你的文件；第三，没网也能用——断网环境下照样传。

**3\. 零配置，即装即用**

    安装后打开就能用，不需要注册账号、不需要登录、不需要配置任何东西。界面就两个大按钮——「发送」和「接收」，选好文件点一下就传过去了。连我那个不太会用电脑的同事都能秒上手。

**4\. 支持所有文件类型**

    照片、视频、文档、压缩包、文本——什么都能传。最重要的是，不会压缩画质！微信传图片会压缩到模糊，LocalSend 传的是原图原画，这一点就值了。

##  怎么用？3步搞定 

    用法超简单，真的只要3步：

**第一步** ：在你的手机和电脑上都安装 LocalSend（安卓去 GitHub 下载 APK，iOS 去 App Store 搜「LocalSend」，电脑端去官网下载对应版本）。

**第二步** ：确保两台设备连着同一个 WiFi，打开 LocalSend。软件会自动发现附近的设备，你会看到设备名称（比如「快乐的菠萝」之类的随机昵称）。

**第三步** ：点击「发送」，选择要传的文件，点击目标设备名称，对方点击「接受」就搞定了。整个过程不超过10秒。

    小提示：你还可以在设置里开启「自动保存」，这样接收文件时就不需要每次都点「接受」了，适合经常传文件的场景。
