你有没有遇到过这种情况：想快速调整窗口大小，却发现 Windows 原生功能根本不支持？想批量重命名文件，却只能一个个手动改？微软其实早就给你准备好了神器——PowerToys，只是你可能还不知道。

## PowerToys 是什么？

PowerToys 是微软官方出品的一套免费开源系统增强工具集。说白了，就是微软觉得 Windows 原生功能不够用，自己又不好意思承认，于是默默做了一堆好用的小工具塞在里面。

## 必备工具推荐

![](https://img.88531.cn/i/2026/08/26/6a8e3c827d31a.png)

**FancyZones 窗口管理** ：自定义窗口布局，一键把窗口拖到指定位置。比如左边放浏览器，右边放编辑器，下方放终端——三分屏一步到位。用过之后再也回不去了。

**PowerRename 批量重命名** ：选中一堆文件，用正则表达式或简单替换规则批量改名。照片按日期排序、文档统一加前缀，几秒钟搞定原来要半小时的工作。

**Color Picker 取色器** ：按下快捷键，鼠标指到哪里就取哪里的颜色值。设计师和前端开发者的福音，再也不用开 Photoshop 取色了。

**PowerToys Run 启动器** ：类似 macOS 的 Spotlight，输入几个字母就能快速启动程序、搜索文件、执行计算。比 Windows 自带的搜索快太多了。

**Image Resizer 图片缩放** ：右键图片就能批量调整尺寸，支持自定义预设。发邮件、上传网站前快速压缩图片，非常方便。

## 如何安装？

直接在 Microsoft Store 搜索「PowerToys」就能安装，或者去 GitHub 下载安装包。安装后在系统托盘找到图标，右键就能打开设置界面，按需启用各个模块。
